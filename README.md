# Scoped FS Access\n\nA small Node library that confines filesystem reads and writes to a single root directory. Every path you pass is resolved against that root and rejected if it would escape.\n\n```js\nimport { ScopedFS } from 'scoped-fs-access';\nimport nodeFs from 'node:fs';\nimport nodePath from 'node:path';\n\nconst fs = new ScopedFS('/var/data/myapp', { fs: nodeFs, path: nodePath });\n\nfs.writeFileSync('config.json', '{"ok":true}');\nfs.readFileSync('config.json');              // '{"ok":true}'\nfs.writeFileSync('../escape.txt', 'x');     // throws: escapes sandbox root\nfs.readFileSync('/etc/passwd');             // throws: absolute paths are not allowed\n```\n\n## Why\n\nWhen an application accepts filenames from untrusted input — uploads, user-named assets, plugin data — a naive `path.join(root, userInput)` is a containment hole. `ScopedFS` exists to make the boundary check the default rather than something every call site has to remember.\n\nThe trade-off: `ScopedFS` uses **lexical** path resolution, not physical symlink resolution. A symlink inside the sandbox whose target points outside it is not detected. If you need that, resolve symlinks yourself first and scope the resolved path. This keeps the containment check a pure function of the path string, with no filesystem reads during validation — which in turn is what makes it testable with an in-memory fake.\n\n## The awkward edge\n\n`..` segments are allowed as long as the final resolved path is still under root. `a/../b` resolves to `b` and is fine. `..` on its own resolves to the parent of root and is rejected. Absolute paths (`/etc/passwd`) are rejected outright rather than silently rewritten — if a caller passes one, that is a bug worth surfacing.\n\n## API\n\n`new ScopedFS(root, { fs, path })` — construct with a root (relative paths resolved against `process.cwd()` at construction). Inject `fs` and `path` to substitute fakes; both default to the real `node:` modules.\n\n- `sfs.root` — the normalised root path.\n- `sfs.readFileSync(rel)` — returns UTF-8 string.\n- `sfs.writeFileSync(rel, data)` — writes UTF-8. Parent directories must exist.\n- `sfs.unlinkSync(rel)`\n- `sfs.existsSync(rel)` — returns boolean.\n- `sfs.statSync(rel)` — returns `fs.Stats`.\n- `sfs.mkdirSync(rel)` — parent must exist.\n- `sfs.readdirSync(rel)` — returns entry names.\n\nAll methods throw if the resolved path leaves the sandbox.\n
